Frequently Asked Questions

Berapa lama estimasi pengerjaan website? expand_more

Untuk paket Starter pengerjaan berkisar 7–14 hari kerja. Paket Bisnis Pro memerlukan waktu 3–4 minggu, sementara web aplikasi custom enterprise disesuaikan dengan roadmap spesifikasi modul (umumnya 6–10 minggu).

Apakah kepemilikan source code diserahkan 100%? expand_more

Ya. Setelah pelunasan, seluruh aset desain Figma, repositori kode (GitHub/GitLab), dan hak akses hosting/domain diserahkan seutuhnya menjadi hak milik bisnis Anda.

Apakah website sudah dioptimasi untuk SEO Google? expand_more

Tentu. Semua kode kami ditulis semantik sesuai standar Google On-Page SEO, mencakup sitemap XML, robots.txt, OpenGraph media sosial, serta schema data terstruktur.

Bagaimana sistem termin pembayarannya? expand_more

Skema standar adalah DP 50% di awal kontrak, dan pelunasan 50% setelah website lolos tahap testing di server staging dan siap dipindahkan ke domain utama Anda.

Apakah ada garansi jika terjadi error atau bug? expand_more

Setiap paket dilengkapi garansi teknis gratis mulai dari 3 hingga 12 bulan untuk perbaikan bug dan kendala fungsional tanpa dipungut biaya tambahan.
